Executable Environments for Evaluating Agentic Risk

18 August 2026 · Research notes

Preview article. This page demonstrates the typography and structure of a future blog post; it is not presented as a published research claim.

Evaluating an autonomous agent is not only a matter of writing a difficult prompt. The environment around the agent determines what actions are possible, which state transitions are valid, and whether a successful trajectory can be reproduced.

Why execution matters

A purely generative simulator can create diverse situations quickly, but it may also invent state changes that violate the rules of the task. Encoding critical state transitions in executable logic gives an evaluation a stable backbone while leaving room for natural-language interaction.

A practical separation

One useful design is to separate deterministic state from generative narrative. Code governs the facts that must remain consistent; a language model supplies the flexible surface through which an agent observes and acts. The boundary between those two layers is itself part of the safety design.

What I would test next

I would look for failure modes that appear only across long trajectories: accumulated state errors, reward shortcuts, and policies that exploit ambiguity between the executable and narrative layers.
